# AI Imposter – Anime & Cartoons

A fun multiplayer **Imposter party game** themed around:

- Naruto
- Hunter × Hunter
- Attack on Titan
- SpongeBob
- Mario

Pass-the-phone style. Perfect for parties.

## How to play

1. Add 3+ players
2. Pick categories
3. Choose number of Imposters
4. Start game → pass the phone so each player secretly sees their role
5. Play 5 rounds of clues + discussion
6. Round 6 → vote → reveal who the Imposter was

**Crew** see the secret word.  
**Imposters** only see the category.

## Deploy to Vercel (2 minutes)

### Option A – Drag & Drop (fastest)

1. Go to [vercel.com/new](https://vercel.com/new)
2. Drag the entire `ai-imposter-vercel` folder onto the page
3. Click **Deploy**
4. Done! You’ll get a live URL

### Option B – GitHub (recommended)

1. Create a new GitHub repository
2. Upload all files from this folder
3. Go to [vercel.com/new](https://vercel.com/new)
4. Import the GitHub repo
5. Click **Deploy** (no settings needed)

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000
